☢️ Create: Nuclear Shell — NeoForge Edition

Nuclear artillery for Create: Big Cannons on Minecraft 1.21.1 / NeoForge.
One shell. One crater. Everything else is scenery.

💥 What is it?

A high-impact expansion for Create: Big Cannons that adds a craftable Nuclear Shell: a single-use artillery round that turns the impact zone into a glowing, irradiated crater and leaves a mushroom cloud hanging over the battlefield.

This is the NeoForge edition of Create: Nuclear Shell. It replaces the archived Forge 1.20.1 version and — unlike it — does not depend on Alex's Caves anymore.

✨ Features

  • 💣 Nuclear artillery shell with a massive blast radius (35 blocks by default)
  • ☢️ Radiation, poison and blindness for everything caught in the blast
  • 🌋 Mushroom cloud that unfolds over several seconds and is visible from far away
  • 🔥 Fire, knockback and screen shake for nearby players
  • 🕳️ Progressive crater — the ground is dug block by block, from the centre outwards
  • 🧪 Sequenced assembly recipe for the shell (5 steps, 4 loops)
  • ⌨️ /nuke [radius] command for testing (operator permission level 2)
  • ⚙️ Fully configurable — blast radius, damage, radiation, crater speed, screen shake

🧪 How to craft it

The shell is made in a Sequenced Assembler:

Sturdy Sheet → Deploy TNT → Press → Deploy Precision Mechanism → Deploy Brass Sheet → Press

Loop the sequence 4 times for an 85% chance of a finished shell.

⚙️ Configuration

The config file is config/canonnukes-common.toml:

KeyDefaultDescription
explosion.blastRadius35.0Blast radius of the shell in blocks
explosion.damageMultiplier1.0Multiplier for the damage to entities
explosion.destroyBlockstrueWhether the blast digs a crater
explosion.craterSteps40Steps the crater is dug over
explosion.craterStepInterval2Ticks between two crater steps
effects.radiationtrueWhether the blast irradiates entities
effects.radiationDuration800Duration of the radiation (20 ticks = 1s)
effects.screenShaketrueWhether the screen shakes
effects.mushroomCloudtrueWhether the mushroom cloud is rendered
